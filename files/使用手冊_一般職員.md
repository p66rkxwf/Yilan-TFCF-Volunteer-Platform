# 宜蘭家扶志工平台使用手冊（一般職員版）

適用對象：一般職員（role：staff，含社工職稱）
版本：2026-07
其他手冊：系統管理員 ／ 單位管理員 ／ 志工

本手冊提供後台一般職員之操作說明，涵蓋活動、報名、簽到、學生資料等日常營運工作，並明確列出須由單位管理員以上始能操作之功能。

> **日期與時間之顯示格式：** 全系統一律採 `YYYY-MM-DD`（例如 `2026-08-14`）與 24 小時制 `HH:mm`（例如 `09:00`），日期一律補零並標示年份；場次日期另於括號內標示單字星期（例如 `2026-08-14（五）`）。輸入日期時請沿用相同格式，系統亦接受以 `/` 分隔之輸入並自動轉換。

## 1. 您的權限範圍

後台帳號分為三種角色：**一般職員（staff）**、**單位管理員（unit_admin）**、**系統管理員（system_admin）**。「社工」為職稱而非角色——是否具社工職稱，僅影響能否被指派為學生之負責社工並收取相關通知，不會擴大或縮減下列操作權限。本章為一般職員角色之權限總覽：

| 工作項目 | 是否可操作 |
|---|---|
| 學生名冊查詢、手動新增學生、編輯任一學生之基本資料 | 可以 |
| 活動／場次之新增、編輯、發布、截止、取消、指派學生 | 可以（任何人建立之活動皆可管理） |
| 報名審核、取消審核（含批次） | 可以 |
| 出席簽到、標記缺席、補登出席 | 可以 |
| 自訂服務時數審核、代任一志工登錄 | 可以 |
| 公告之新增、編輯、發布、下架、置頂 | 可以 |
| 支援需求收件匣查看與標記已處理 | 可以 |
| 報表查詢與多數 CSV 匯出 | 可以（操作紀錄、職員名冊兩項匯出除外） |
| 「帳號設定」自改個人資料（電話、地區、Email、帳號）與密碼 | 可以（姓名與職稱僅系統管理員可改） |
| 新帳號審核、停用申請審核 | 否，僅單位管理員以上 |
| 學生狀態變更（停權／復職／畢業結案）、手動加入黑名單、黑名單延長或提前解除 | 否，僅單位管理員以上 |
| 學生負責社工改派（單一或批量）、學生密碼重設 | 否，僅單位管理員以上 |
| 年度審查之決策操作（更新學制／標記已審／畢業結案） | 否，僅單位管理員以上（可唯讀查看） |
| 職員帳號管理、系統設定、操作紀錄、封存／永久刪除 | 否，僅系統管理員 |

> **功能未顯示屬正常設計，並非系統故障：** 後台將依角色自動隱藏您無法操作之按鈕與頁面。若工作上需使用標示為「否」之項目，請洽單位管理員或系統管理員協助處理，詳見第 13 章。

## 2. 登入後台與儀表板

以您的職員帳號密碼登入後，將直接進入後台。若帳號係新建立或密碼曾經重設，請使用系統管理員轉告之臨時密碼登入，首次登入將強制要求先設定新密碼始能繼續使用。

儀表板首頁彙整六類待辦提醒（待審報名、取消審核、逾期待辦、帳號審核、停用申請、目前黑名單）與未來 7 日之場次總覽，俾便快速掌握當日工作重點；三種角色所見之儀表板內容完全相同，惟點選進入「帳號審核」等您無權限之項目時，該頁將顯示提示文字而非表單內容。

「未來 7 天場次」係以**日期分組之清單**呈現，同一日之場次歸於「今天」「明天」或日期小標（例如 `2026-08-14（五）`）之下，每列僅顯示時段而不重複日期；跨日場次之結束時間將另標日期（例如 `20:00 – 2026-08-14 06:00`）。

> **列表點兩下即可開啟：** 後台各張列表（活動、公告、年度審查、出席簽到、黑名單、報名審核、停用申請、學生名冊）以及活動詳情頁之場次表，於任一列**點兩下**即可開啟該列之管理頁，毋須精準點中該列之文字連結。點在按鈕、核取方塊或「操作」選單上則不會觸發。原有之文字連結完全保留，使用鍵盤或螢幕閱讀器者請沿用該連結。
>
> **點欄位標題即可排序：** 後台各張列表之欄位標題皆可點選排序，各欄依其本身之資料排列——時間欄依時間、活動欄依名稱、時數與筆數欄依數值。**點第一次為遞增、第二次為遞減、第三次則回復該頁原本之預設順序**（例如報名審核預設由舊至新，俾便依序處理，排序後仍可點回該順序）。
>
> 狀態與學制欄位係依其**流程順序**而非中文筆畫排列，例如報名狀態依「待審核→已核准→已拒絕→取消待審→已取消→已過期」、學制依「國中→高中→大學→研究所→博士」。排序範圍為**篩選後之全部資料**而非當前頁面，故於分頁清單點選排序後，第 1 頁所顯示者即為全部資料中之首幾筆；惟排序僅暫存於當前畫面，重新整理或離開該頁後即回復預設順序。「操作」欄，以及帳號審核之「負責社工」、年度審查之「更新為」等欄內為下拉選單者，因屬操作介面而非資料，不提供排序。

## 3. 學生名冊管理

### 查詢學生

「學生」名冊列出姓名、學制、地區、電話、負責社工與狀態，可搜尋與篩選。

### 手動新增學生帳號

點選「手動新增學生」填寫基本資料後建立帳號，建立時狀態直接為「正常」（毋須經過帳號審核流程），惟**必須同時指定一位在職之負責社工**，下拉選單僅列出職稱為社工之在職職員。建立完成後畫面將顯示系統產生之臨時密碼（**僅顯示一次**，可按「複製」），請轉告該學生；該學生首次登入須自行設定新密碼。

### 編輯學生基本資料

進入學生詳情頁後，可直接編輯姓名、電話、地區、生日並儲存，**此功能任何在職職員皆可操作**，不限管理員身分。學生之「聯絡 Email」與「登入帳號」兩欄僅系統管理員可見與代改（代改 Email 將重置該生之驗證狀態），一般職員之編輯視窗不顯示該兩欄。

> **可檢視但無法操作之部分：** 學生詳情頁上方將顯示黑名單紀錄、目前狀態與負責社工等資訊，惟「操作」選單（停權／復職／畢業結案／加入黑名單／重設密碼／改派負責社工）僅單位管理員以上始會顯示，一般職員於此頁面無法看到該選單。

## 4. 活動與場次管理

本平台刻意將活動管理權限開放予**所有在職職員**，不限建立者或負責人本人，俾便小型單位彈性支援彼此之活動。

- **新增活動**：填寫名稱、說明、地點、負責人等資訊；「負責人」可自所有在職職員中選擇，不限社工職稱，經選為負責人者將收取新報名與審核提醒通知。**活動說明支援 Markdown 語法**（粗體、清單、引用、連結等），編輯區附工具列與「編輯／預覽」切換。
- **編輯活動**：可修改任何人建立之活動，包含尚未發布之草稿。
- **發布 / 截止 / 取消活動**：變更活動之開放狀態；取消整場活動將連動處理相關報名與通知，操作前設有二次確認提示。
  - **發布活動**係活動建立流程之終點，故獨立為活動詳情頁右上角之主要按鈕（不在「操作」選單內）。**尚未建立任何有效場次時該按鈕呈停用狀態**，滑鼠停留其上會顯示「請先新增至少一個場次」；草稿狀態之活動頁面頂端亦常駐一條提示，標示目前是「需至少一個場次才能發布」或「可按右上角發布」。
- **新增 / 編輯場次**：於活動詳情頁點選「新增場次」或「一次加多場」，將**就地開啟對話框**，毋須離開該頁。**日期以點選日曆選取、時間直接輸入數字**（免打冒號，例如輸入 `1400` 自動成為 `14:00`）。
  - 對話框於新增成功後**不會關閉**，僅清空日期而保留時段、名額與地點，可直接接著建立下一場；建完全部場次後按「關閉」即可，清單會即時更新。
  - **場次類型**：可選「正式場次」或「行前說明會」。行前說明會同樣開放志工報名、可點名，且可勾選「此說明會出席是否計入服務時數」（正式場次一律計）。
  - **場次地點**：留空即沿用活動之主要地點；填寫則該場次改於此地點，方便不同場次於不同地點舉行。
  - **補充說明**：行前說明會可另填說明（集合方式、線上連結、注意事項等），顯示於志工端。
- **取消場次 / 刪除場次**：兩者不同——「**取消場次**」保留紀錄，並連動取消已報名、逐筆通知志工（颱風停辦等）；「**刪除場次**」為整筆移除，僅限**尚無任何報名紀錄**（含已取消之報名）之場次，用於誤建之場次。
- **指派學生至場次**：可略過志工自行報名之流程，直接將指定學生安排至某場次（等同直接核准），常用於確定參與但尚未自行報名之情形。

> **取消為不可逆之操作：** 取消活動或場次將觸發二次確認對話框，確認後即直接影響已報名志工並發出通知，請確認資訊無誤後再執行。

活動與場次本身之「封存」「永久刪除」僅系統管理員可操作，一般職員於活動列表無法看到此兩項選項。

## 5. 報名審核與取消審核

「報名管理」頁分為「待審核報名」「取消審核」「逾期待辦」三個分頁：

- **待審核報名**：逐筆或批次核准／拒絕志工之新報名申請。
- **取消審核**：處理志工申請取消已核准報名、且依規則須經審核之案件，核准或駁回後志工將收取通知。
- **逾期待辦**：提示尚未處理、即將逾期之待審項目。

此頁面**對所有在職職員完全開放**，不限管理員身分，為日常工作量最大之頁面之一。

## 6. 出席簽到與補登

「出席」頁可查看各場次之報名名單並代為登記出席、標記缺席；志工錯過簽到時間寬限期後，仍可由職員手動「補登出席」，補登時系統將自動核算服務時數（惟若該場次為設定「不計入服務時數」之行前說明會，登記出席不會累計時數）；若該志工因該案而列於限制名單中，補登出席亦可能連動提前解除限制名單。此功能對所有在職職員開放。

## 7. 自訂服務時數審核

「自訂服務審核」頁分為兩部分：

- **審核收件匣**：志工自行送出之私下服務登錄，逐筆核可或退回（退回可附說明，志工將於自身頁面看到）。
- **代志工登錄**：可代**任一**在職志工（不限自己負責之學生）登錄一筆私下服務紀錄並直接送審。

此功能對所有在職職員開放。核可後之時數將自動併入該志工之服務時數統計與服務證明書。

## 8. 公告管理

可新增、編輯、發布、下架、置頂公告，對所有在職職員開放。公告之「封存」與「永久刪除」僅系統管理員可操作。

公告發布後，所有人（包含未登入之訪客）皆可於網站首頁與「最新消息」頁瀏覽；草稿、已下架與已封存之公告僅職員可見。

## 9. 支援需求收件匣

可查看前台「聯絡支援」頁送出之所有問題（含未登入訪客送出者），並將已處理之項目標記完成或重新開啟，對所有在職職員開放。

## 10. 報表與統計

「報表」頁提供 KPI 統計與多種篩選查詢，一般職員可匯出：學生名冊、服務時數、活動成效、出席明細、黑名單、期間達標、公告清單等 CSV 報表。

> **兩項匯出僅系統管理員可用：** 「操作紀錄」CSV 屬稽核資料，僅系統管理員可匯出與查看；「職員名冊」CSV 按鈕亦僅系統管理員可操作，惟此僅為介面上之匯出便利性限制——職員名冊本身於「職員」頁面對所有在職職員皆可查詢瀏覽，並非機密資料。

## 11. 年度審查（唯讀）

「年度審查」頁列出建議更新學制階段或結案之學生清單，一般職員可查看此清單，惟**無「更新為」欄位與操作選單**——實際更新學制、標記已審、辦理畢業結案，須由單位管理員以上執行。

## 12. 帳號設定

點選後台**側欄下方之個人名牌**（頭像與姓名）即可進入「帳號設定」頁，全體職員不限角色皆可使用：

- **個人資料**：可自行修改電話、地區、Email 與帳號。Email 同時為您的登入信箱、帳號為您的登入帳號，變更後即刻生效——下次登入請改用新帳號（密碼不變）；帳號須全平台唯一，與任何職員或學生重複時將無法儲存。
- **姓名與職稱**：僅供檢視，由系統管理員維護，如需修改請洽系統管理員。
- **修改密碼**：輸入新密碼（至少 8 個字元）並再次確認後即可變更，變更後不會被登出。
- **信件通知偏好**：可自行關閉下列提醒／待辦類信件之寄送——

  | 可自行關閉之信件 | 何時會收到 |
  |---|---|
  | 【主辦提醒】有待審核的報名 | 您負責之活動有報名逾期未審 |
  | 【審核提醒】有新的活動報名 | 有學生送出新報名（通知主辦人與該生負責社工） |
  | 【審核提醒】有新的志工帳號待審核 | 有新帳號待審（單位管理員以上才會收到） |
  | 【審核提醒】有志工上傳自訂服務待審核 | 您負責之學生送出自訂服務登錄 |
  | 【社工提醒】志工提出帳號停用申請 | 您負責之學生申請停用帳號 |
  | 場次時間異動造成的時段衝突提醒 | 場次改期後偵測到時段可能衝突 |

  關閉的**只是寄信**，該則訊息仍會出現在站內通知，不會漏接。審核結果、活動或場次取消等重要通知，以及 Email 驗證碼信，一律寄送、不可關閉。
  此處只影響**您本人**收信；若某類信件已由系統管理員於「系統設定」全站關閉，此處會標示為已被全站關閉。

> **自改資料亦留有紀錄：** 於帳號設定頁之修改將記入操作紀錄（稽核日誌），與其他後台操作相同。

## 13. 您看不到的功能

下列功能之整頁或整組選單將被隱藏，此為正常設計，並不代表系統故障：

| 功能 | 需要的角色 | 看到的畫面 |
|---|---|---|
| 新帳號審核 / 停用申請審核 | 單位管理員以上 | 整頁顯示「此頁僅限單位管理員以上操作」 |
| 學生狀態變更、手動加入黑名單、黑名單調整 | 單位管理員以上 | 學生詳情頁 / 黑名單頁之「操作」選單不顯示 |
| 負責社工改派、學生密碼重設 | 單位管理員以上 | 對應按鈕不顯示 |
| 年度審查決策操作 | 單位管理員以上 | 僅可查看清單，無操作欄 |
| 職員帳號管理（新增、批量匯入、角色變更、停權、密碼重設、編輯職員資料） | 系統管理員 | 職員名冊「操作」欄整體不顯示 |
| 學生「聯絡 Email」「登入帳號」之代改 | 系統管理員 | 學生編輯視窗不顯示該兩欄 |
| 系統設定（參數、保留期、期間管理、時數門檻） | 系統管理員 | 頁面可進入，惟全部欄位唯讀 |
| 操作紀錄（稽核日誌） | 系統管理員 | 側欄無此項目，直接輸入網址將被導回後台首頁 |
| 封存 / 永久刪除（學生、職員、活動、公告） | 系統管理員 | 對應選項不顯示 |

需使用上列功能時，請洽單位管理員或系統管理員協助處理。

## 14. 常見狀況 Q&A

**欲修改自己的姓名或職稱，應如何處理？**
「帳號設定」頁僅開放自行修改電話、地區、Email 與帳號；姓名與職稱由系統管理員統一維護，請洽系統管理員代為修改。

**學生詳情頁未顯示「停權」「加入黑名單」按鈕，原因為何？**
此等功能屬單位管理員以上之權限，一般職員之帳號於該頁不顯示操作選單，屬正常情形。請洽單位管理員處理。

**可否為非本人負責之學生登錄自訂服務或審核其申請？**
可以。自訂服務之審核與代志工登錄對所有在職職員開放，不限負責社工本人；系統僅將「送審通知」發予該志工之負責社工，不影響審核或代登錄之權限。

**可否管理非本人建立之活動？**
可以。本平台已將活動管理權開放予所有在職職員，任何人皆可編輯、發布、取消其他同仁建立之活動與場次。

**「報表」頁之職員名冊匯出按鈕呈停用狀態，是否代表無權查看職員資料？**
否。職員名冊本身於「職員」頁面對所有在職職員皆可查詢瀏覽，僅報表頁之 CSV 匯出功能限系統管理員使用，屬介面便利性限制，而非資料保密限制。

**新建學生帳號須指定負責社工，惟下拉選單中找不到欲指定之職員，應如何處理？**
負責社工下拉選單僅列出職稱設定為「社工」且在職之職員。若對方應為社工卻未出現於清單，可能為職稱設定或在職狀態之問題，請洽系統管理員確認該職員帳號之職稱設定。
